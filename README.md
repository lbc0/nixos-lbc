# NixOS-lbc

Personal NixOS + Home Manager flake configuration, managed via [Nix flakes](https://nixos.wiki/wiki/Flakes) and [sops-nix](https://github.com/Mic92/sops-nix) for secrets.

## Setup checklist for a new machine / new user

Before running `nixos-rebuild switch` (aliased as `nrs`) on a fresh clone of this repo, you need to change a few machine- and user-specific things. 

### 1. Clone the repo to the expected path

This flake assumes it lives at a fixed path on disk (`repo` in `flake.nix`), since some live-editable configs (e.g. Niri) are symlinked directly to files on disk rather than copied through the Nix store.

```bash
git clone <this-repo-url> ~/nixos-lbc
```

If you want it somewhere else, update the hardcoded path in `flake.nix`:

```nix
repo = "/home/<your-username>/nixos-lbc"; # live checkout on disk
```

> This is one of the few places a literal path is unavoidable — Nix evaluation can't read `$HOME` or other shell variables at build time, so this has to be a fixed string.

### 2. Replace the hardware configuration

Each host has its own hardware config generated by the NixOS installer. Yours will differ from mine.

```bash
nixos-generate-config --show-hardware-config > hosts/<work|home>/hardware.nix
```

Replace the placeholder file at `./hosts/work/hardware.nix` or `./hosts/home/hardware.nix` (whichever host you're setting up) with your own.

### 3. Add your SOPS age key

Secrets (`hosts/common/secrets/secrets.yaml`) are encrypted with [sops](https://github.com/getsops/sops) using an [age](https://github.com/FiloSottile/age) key. You need your own key — you cannot use mine, since the secrets file is encrypted specifically for my public key.

1. Generate a new age key: 
   ```bash
   mkdir -p ~/nixos-lbc/.ignore
   age-keygen -o ~/nixos-lbc/.ignore/.keys.txt
   chmod 600 ~/nixos-lbc/.ignore/.keys.txt
   ```
2. Note the public key printed by `age-keygen` (starts with `age1...`).
3. Add your public key to `.sops.yaml` at the repo root, and re-encrypt `secrets.yaml` for it (see the [sops-nix README](https://github.com/Mic92/sops-nix) for the `updatekeys` workflow).

> **Never commit `.ignore/.keys.txt`.** Confirm it's listed in `.gitignore` before doing anything else. This file is your private decryption key — anyone who reads it can decrypt every secret in this repo.

### 4. Update personal identity / account details

A few values are hardcoded to me specifically and should be changed to yours:

| File | What to change |
|---|---|
| `home/lbc/common/config.nix` | `programs.git.settings.user.name` / `.email` |
| `flake.nix` | `home-manager.users.<username>` — replace `lbc` with your username throughout the flake and host modules if your username differs |
| `home/lbc/*/scripts.nix` | `gitup` script pushes to branch `nix-work` — change to your preferred branch name if different |
| `hosts/*/default.nix` | `networking.hostName` — already set per-host (`lbcw`, `lbch`); rename hosts as you like, just keep `flake.nix`'s `nixosConfigurations.<name>` and your `nrs` alias's `--flake ...#<name>` in sync |

### 5. Review secrets-dependent scripts

Several convenience scripts in `scripts.nix` read from `/run/secrets/...` (populated by sops-nix at activation) — e.g. `nac`, `bao-login`, the `element-desktop` password wrapper, and the git credential helper. These will fail until:
- Your own secrets are present in `secrets.yaml` under the same keys, **or**
- You remove/adjust the scripts that reference secrets you don't have.

### 6. First build

```bash
cd ~/nixos-lbc
git add -A   # flakes only see git-tracked/staged files
sudo nixos-rebuild switch --flake .#<hostname>
```

Once this succeeds, the `nrs` shell alias (defined in `home/lbc/common/config.nix`) will work for all future rebuilds.

## Repo layout

```
flake.nix                 # entry point; defines hosts, repo/store path vars
hosts/                     # per-host NixOS config (hardware, host-specific settings)
home/lbc/                  # Home Manager config, split by profile (work/home) + common
config/                    # live dotfiles (niri, quickshell, swayidle, ...) — symlinked, not copied
.local/bin/                # standalone scripts wrapped into packages via scripts.nix
.ignore/                   # gitignored — local secrets/keys, never committed
```

## Notes

- Niri and other live-editable configs are symlinked via `mkOutOfStoreSymlink` rather than copied into the Nix store, so you can edit them directly and see changes without a rebuild. This trades off some safety (anyone with access to your unlocked session can edit them) for convenience — see the security notes in commit history / project discussion if you want to harden this.
- `DOTFILES_ROOT` (Nix store snapshot, updates on rebuild) and `DOTFILES_LIVE` (live disk path, always current) are both exported as session variables — use whichever fits a given script's needs.
